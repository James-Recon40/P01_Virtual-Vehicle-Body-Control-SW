# web - VBC 웹 UI (feature/ui)

가상 차량(자동차·주변 환경·계기판)과 입력 툴바로 VehicleController를 조작하고, 05 블랙박스 테스트케이스를 시연한다.

근거: 04 SW 상세설계서 v1.1 `18_UI_연동`, 03 인터페이스 정의서 v1.4 개요 B7~B10

## 실행

```bash
python3 web/server.py            # http://127.0.0.1:8080/ 을 브라우저로 연다
python3 web/server.py --port 9000
```

- 필요한 것: Python 3.8+, gcc (외부 패키지 설치 없음)
- 시작할 때 `src/*/*.c`를 `web/build/libvbc.so`로 빌드하고 ctypes로 불러온다. 기능 로직은 C 코드만 쓴다.
- 50 ms마다 `VehicleController_Step(now_ms)`를 호출한다 (now_ms = 0, 50, 100, ...).

## 구성

| 파일 | 역할 |
|---|---|
| `server.py` | 브리지 서버. 정적 파일 + WebSocket(`/ws`) 제공, C 모듈 빌드·호출 |
| `bridge/vbc_bridge.c` | ctypes 구조체 배치가 C와 같은지 확인하는 보조 함수 |
| `stubs/*_stub.c` | **[임시]** `src/wiper`, `src/lighting`에 `.c`가 없을 때만 링크. 항상 초기값(정지/꺼짐)을 반환 |
| `static/index.html`, `style.css`, `app.js` | 화면 |
| `static/presets.js` | TC 사전조건 프리셋 (05 문서 '사전조건' 열 기준) |
| `static/testcases.json` | 05 테스트케이스 원문 (`tools/extract_testcases.py`로 생성) |
| `tools/extract_testcases.py` | 05 엑셀 → `testcases.json`. 테스트케이스 문서가 바뀌면 다시 실행 |

## 통신 (UI 담당 결정: WebSocket)

메시지는 18 시트 규격 그대로다.

- UI → VC `{"type":"input","signals":{...}}`
  - 주기 신호 5개는 100 ms마다 한 메시지로 보낸다. 송신 중단한 신호는 메시지에서 뺀다.
  - 이벤트 신호는 값이 바뀔 때 바뀐 신호만 보낸다.
  - 연결·재연결·새로 시작 때 이벤트 신호 6개를 1회 보낸다.
- VC → UI `{"type":"output","time_ms":...,...}` 50 ms마다

18 시트 밖의 시험용 메시지:

| 메시지 | 방향 | 용도 |
|---|---|---|
| `{"type":"reset"}` | UI → 서버 | `VehicleController_Init()` 재호출, 시각 0 (TC 사전조건 '프로그램 새로 시작') |
| `{"type":"reset_done"}` | 서버 → UI | reset 처리 완료 |
| `{"type":"hello","stubs":[...],"step_ms":50}` | 서버 → UI | 연결 직후 1회, 스텁 사용 여부 표시 |

## 화면 기능

- **주기 신호**: 시동, 기어, 속도, 조도, 강우량. 신호마다 송신 중단·재개 버튼이 있고, 모두 중단·모두 재개도 된다 (03 B8).
- **범위 밖 값 (C2 시험)**: 슬라이더가 유효 범위보다 넓다. 숫자 칸에는 제한 없이 입력할 수 있다. 범위 밖 값도 그대로 보낸다.
  - 속도: 슬라이더 -50 ~ 300 (유효 0 ~ 250 km/h)
  - 조도: 슬라이더 -5000 ~ 70000 (유효 0 ~ 60000 lux)
  - 강우량: 슬라이더 -20 ~ 150 (유효 0 ~ 100 %)
  - 경계값 버튼: TC에서 쓰는 값(예: -1, 0, 999, 1000, 60001, 120)을 한 번에 넣는다
- **이벤트 신호**: 조명 스위치, 와이퍼 스위치, 도어 4개 (차량 그림의 도어를 클릭해도 된다)
- **새로 시작**: VC 초기화. '주기 신호 모두 중단 상태로 시작'을 켜면 TC-C4-02·C5용 시험 옵션이 된다.
- **테스트케이스**: 42개 TC의 목적·사전조건·절차·예상 결과를 원문으로 보여 준다.
  - '사전조건 적용'은 새로 시작한 뒤 사전조건 입력을 세팅한다.
  - 절차 실행과 판정은 시험자가 직접 한다.
- **기록**: 입력 송신과 출력 변화를 time_ms와 함께 남기고 CSV로 저장한다 (증거용).
  - 't=0 표시'를 누르면 그 시점 기준의 경과 시간이 함께 기록된다.
